▸ How to use this with Google Forms
Google Forms can't run interactive tools inside a question — it only embeds static images/video. This workaround needs no backend at all:
  1. Host this page (GitHub Pages, Netlify, or a Google Sites "Embed" block all work — it's a single HTML file).
  2. In your Form's description, link to the hosted designer: "Design your shirt here, then paste your Order Code below."
  3. Add a paragraph text question to your Form titled "Order Code."
  4. Customers design here, click Generate Order Code, and paste the resulting text block into that Form field.
The code is a compact encoded blob, not plain text — it packs the shirt color, size, qty, and every layer (text + artwork) into one short string. To turn a submitted code back into a design you can see and print, open it in the companion Order Code Decoder page (paste the code, get the rendered design + a downloadable PNG).
Prices shown are illustrative — swap in your own pricing rules. Designs live only in this browser tab until downloaded or copied.
